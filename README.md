## 🆕 Latest Project

### 📄 [internal-sdk-txt-extractor](https://github.com/sunnysharma4002/internal-sdk-txt-extractor)

Converts Unreal Engine internal SDK headers into readable SDK dump text files. A single Python script (no external packages) generates two separate TXT outputs from an internal `SDK/` folder:

- **SDKU** – a full internal SDK dump
- **SDKW** – an SDKW-style dump, filtered and ordered from a template
